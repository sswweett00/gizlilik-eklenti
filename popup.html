Independent controls: every protection module below can be enabled or disabled separately. The master switch disables the entire extension policy.

Location boundary: the Geolocation API is blocked and common IP-location API lookups are denied, but a website can still derive approximate location from the public IP that receives the connection.

Anonymous-only mode: direct networking is not an available configuration while Privacy Shield is installed and active. If Tor is unavailable, web traffic remains blocked instead of exposing the source IP.

Local Tor mode: routes browser HTTP(S) traffic through 127.0.0.1 via SOCKS5 with no direct fallback. It is zero-cost when Tor is running locally; if Tor is unavailable, web requests fail closed instead of falling back to your normal public IP.

AEGIS-9: for zero-cost website-visible IP anonymity, use Qubes R4.3 + Whonix 18 with anon-whonix → sys-whonix → Tor and a Whonix disposable template. See the repository deployment guide.
